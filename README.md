# Змейка (Изгиб Питона)

Классическая игра «Змейка», реализованная на Python с использованием библиотеки Pygame. Проект выполнен в рамках курса «Python-разработчик» Яндекс Практикума.

## Описание

Игрок управляет змейкой, которая движется по игровому полю 640×480 пикселей, разделённому на клетки 20×20. Цель игры — собирать яблоки, при этом змейка растёт. Игра заканчивается при столкновении змейки с самой собой.

## Управление

| Клавиша | Действие |
|---------|----------|
| ↑ / W | Движение вверх |
| ↓ / S | Движение вниз |
| ← / A | Движение влево |
| → / D | Движение вправо |
